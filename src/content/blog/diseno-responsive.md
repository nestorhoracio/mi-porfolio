## El 60 por ciento del trafico es mobile

En 2026 la mayoria de las visitas a sitios web llegan desde celulares. Un sitio que no se ve bien en mobile pierde mas de la mitad de su audiencia.

## Que es el diseno responsive

Es la capacidad de un sitio de adaptarse a cualquier tamano de pantalla sin perder funcionalidad ni estética.

## Como lo implementamos

- Mobile first: diseñamos primero para pantallas pequenas
- Usamos CSS Grid y Flexbox para layouts flexibles
- Las imagenes tienen max-width 100%
- Los textos usan unidades relativas como rem

## Conclusión

Un sitio responsive no es un extra. Es el punto de partida de cualquier proyecto web profesional.
